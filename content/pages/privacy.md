> 占位模板，请按你实际的部署情况修改后再上线。以下条目对应本仓库**默认行为**。

## 1. 收集什么

- **访问日志**：由反向代理与容器产生，含 IP、时间、路径、User-Agent，用于排错与统计
- **阅读量**：每篇文章的计数器，存在服务器 `data/` 目录（不涉及第三方）
- **访客统计**：可选的地理位置解析（需自行配置 `GEOIP_URL`），只落到地区粒度
- **评论**：使用 giscus，数据存在 GitHub Discussions，适用 GitHub 的隐私政策

## 2. 不做什么

- 不投放广告，不接入第三方统计脚本（除非你自己加）
- 不把访问数据卖给或提供给第三方

## 3. 你的权利

如需删除某条评论，请到对应 GitHub Discussion 操作；其他数据可来信要求删除。

## 4. 联系方式

通过「关于」页提供的方式联系站长。
