              贴士
              
      
                
        
              • 正文里可以写相对路径：![](images/foo.png) 或 ![](./foo.png)，站点会当作 /content-images/foo.png 渲染（Obsidian 把附件目录设成 content/images 就能直接粘图）。
                • 
        
              • 用图床也行，直接贴 URL；想存档就用「图床 URL → 本地」拉回来。
                • 
        
              • 图库会扫描 content/images 与所有文章引用：能看哪些图还没传服务器、哪些没被任何文章引用；删除是先移入回收站，可以恢复。
                • 
        
              • 文章检查 → 一键发布：自动补传文章引用的图 → 提交推送 → 校验公网可访问（防止「文章上线了图却 404」）。
                • 
        
              • 快捷键：Ctrl+Shift+U 读剪贴板图片直接导入；Ctrl+Enter 在文章页=一键发布，其它页=提交推送。
                • 
        
              • 本工具只写 content/images/、指定文章的 md，与 data/ 下的记录（回收站 / 备份 / 历史 / alt）。
